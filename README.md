# 🤖 ربات زیرنویس‌ساز هوشمند تلگرام (Instagram Auto Subtitle)

این پروژه یک ربات تلگرام پیشرفته است که لینک ویدیوهای اینستاگرام (یا فایل‌های ویدیویی ارسالی) را دریافت می‌کند، صدای آن را استخراج کرده و با استفاده از هوش مصنوعی **Google Gemini** به زیرنویس فارسی زمان‌بندی‌شده تبدیل می‌کند. در نهایت، زیرنویس همراه با واترمارک اختصاصی روی ویدیو چسبانده شده و به کاربر تحویل داده می‌شود.

---

## ✨ ویژگی‌های کلیدی

- **دریافت هوشمند ورودی:** پشتیبانی از لینک‌های اینستاگرام (ریلز، پست، تی‌وی) و فایل‌های ویدیویی مستقیم تلگرام.
- **هوش مصنوعی Gemini:** استفاده از مدل‌های `gemini-3.8` با قابلیت Fallback (سوییچ خودکار بین مدل‌ها در صورت خطا یا محدودیت).
- **رندر حرفه‌ای با FFmpeg:**
  - تبدیل دقیق فرمت SRT به ASS برای فونت‌های فارسی.
  - اصلاح خودکار تداخل زمانی (Time Overlap) تولید شده توسط هوش مصنوعی.
  - چسباندن واترمارک اختصاصی (PNG) دقیقاً در زیر زیرنویس.
- **گزارش پیشرفت زنده:** نمایش مراحل پردازش (دانلود، استخراج صدا، هوش مصنوعی، رندر) به صورت یک پیام تعاملی در تلگرام.
- **مدیریت خطا:** دکمه «🔄 تلاش مجدد» در صورت بروز مشکل، بدون نیاز به ارسال مجدد لینک.
- **آماده برای دیپلوی روی Render:** استفاده از Flask و Webhook برای اجرای پایدار روی سرورهای ابری.

## 📂 ساختار پروژه

```text
├── main.py                 # نقطه ورود برنامه
├── bot.py                  # منطق اصلی ربات و وب‌سرور Flask (Webhook)
├── config.py               # تنظیمات و کلیدهای API
├── progress_reporter.py    # مدیریت پیام‌های پیشرفت در تلگرام
├── video_processor.py      # دانلود ویدیو و استخراج صدا (yt-dlp & FFmpeg)
├── gemini_service.py       # ارتباط با API گوگل جمینای
├── renderer.py             # چسباندن زیرنویس و واترمارک (FFmpeg)
├── Dockerfile              # تنظیمات داکر برای نصب FFmpeg
├── requirements.txt        # کتابخانه‌های پایتون
├── cookies.txt             # کوکی اینستاگرام (برای دانلود بدون محدودیت)
├── font/                   # فونت‌های فارسی (مثل Vazir.ttf)
└── assets/                 # فایل واترمارک (watermark.png)

🚀 راه‌اندازی محلی (Local Setup)
۱. پیش‌نیازها
پایتون نسخه 3.9 یا بالاتر

نصب بودن FFmpeg روی سیستم‌عامل

۲. نصب کتابخانه‌ها

# ساخت محیط مجازی
python -m venv venv

# فعال‌سازی (ویندوز)
venv\Scripts\activate
# فعال‌سازی (لینوکس/مک)
source venv/bin/activate

# نصب پیش‌نیازها
pip install -r requirements.txt

۳. تنظیمات اولیه
فایل config.py را باز کنید و مقادیر زیر را وارد کنید:
TELEGRAM_BOT_TOKEN = "توکن_ربات_شما"
GEMINI_API_KEY = "کلید_API_جمینای_شما"

نکته: برای دانلود از اینستاگرام بدون محدودیت، حتماً یک فایل cookies.txt از مرورگر خود اکسپورت کرده و در ریشه پروژه قرار دهید.

۴. اجرای پروژه

python main.py

☁️ دیپلوی روی Render.com
این پروژه برای اجرا روی پلتفرم Render بهینه‌سازی شده است. مراحل کلی:

کدها را روی یک ریپازیتوری Private در گیت‌هاب پوش کنید.

در Render یک Web Service جدید بسازید و به ریپازیتوری متصل کنید.

در بخش Runtime گزینه Docker را انتخاب کنید (چون فایل Dockerfile حاوی نصب FFmpeg است).

در بخش Environment Variables متغیرهای زیر را اضافه کنید:

TELEGRAM_BOT_TOKEN

GEMINI_API_KEY

برای جلوگیری از خوابیدن سرور (Sleep) در پلن رایگان، از سرویس UptimeRobot استفاده کنید و هر ۱۰ دقیقه به آدرس سرویس خود پینگ بفرستید.

🛠 تکنولوژی‌های استفاده شده
Python 3.11

pyTelegramBotAPI: مدیریت ربات تلگرام

Flask: وب‌سرور برای دریافت Webhook

yt-dlp: دانلود ویدیو از اینستاگرام

FFmpeg: پردازش و رندر ویدیو

Google Gemini API: تبدیل گفتار به متن و ترجمه

⚠️ نکات مهم
کتابخانه Pillow: برای رندر واترمارک دیگر به این کتابخانه نیازی نیست (واترمارک مستقیماً از یک فایل PNG طراحی شده در فتوشاپ استفاده می‌کند).

کوکی اینستاگرام: فایل cookies.txt به دلیل حساسیت بالا باید فقط در ریپازیتوری خصوصی (Private) نگهداری شود.

محدودیت تلگرام: حداکثر حجم ویدیوی قابل ارسال توسط ربات‌های تلگرام ۵۰ مگابایت است. برای ویدیوهای بزرگ‌تر ممکن است نیاز به استفاده از Local Bot API Server داشته باشید.
